# 假设记录

每个待检验的假设单独建一个文件，命名为 `HXXX-简称.md`（如 `H001-z340-key-reuse-z32.md`）。

规则：

- **运行前**填写“密码体制假设”“参数空间与自由度”“打分函数与判定阈值”“零假设对照设计”四项，并提交；运行后不得修改这四项。
- 负面结果（“不支持”）与正面结果一样需要记录并保留。
- 验收标准见 [../docs/roadmap.md](../docs/roadmap.md) 第 1 节。

## 模板

```markdown
# HXXX：假设名称

- 提出日期 / 提出人：
- 目标密文：Z13 / Z32
- 密码体制假设：（替换 / 同音替换 / 换位 / 组合；密钥来源）
- 参数空间与自由度估算（bits）：
- 打分函数与判定阈值（运行前写定）：
- 零假设对照设计：
- 运行记录（代码版本、随机种子、耗时）：
- 结果：（含前 N 名候选与对照组分布）
- 结论：支持 / 不支持 / 无法判断
```
