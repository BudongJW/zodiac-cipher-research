# H004：把轮换似然加入目标函数，能否降低可解长度门槛？

- 提出日期 / 提出人：2026-09-27 / 本项目
- 目标：方法学检验（结果决定是否值得把该求解器用于 Z32，见 [cycle-report](../docs/cycle-report.md)）
- 动机：M2 显示长度 ≤ 150 时，语言求解器总能找到比真实明文“更像英文”的错误解；方向 F 的分析显示，这些错误解大多违反 Zodiac 的同音分配与轮换习惯（32 字符时 67–96%，50 字符以上 100%）。
- 密码体制假设（合成数据）：
  - 明文：Zodiac 自己的英文（同 M2）；
  - 密钥：每个字母的同音数在 `homophone_prior()` 给出的范围内**随机**选取（不直接使用 Z340 的同音数，避免与打分所用先验循环论证）；
  - 加密：带错误的轮换模型，**ε_gen = 0.4**（与 Z340 书写顺序拟合值相同，偏保守）。
- 参数空间：长度 L ∈ {32, 50, 75, 100}，每个长度 12 次试验；对每份密文比较两类求解器（相同的随机重启数 8 与扫描次数：L ≤ 50 为 400，其余 800）：
  - **基线**：仅语言目标（与 M2 相同）；
  - **轮换感知**：语言目标 + λ × 轮换对数似然，λ ∈ {1, 3, 10}（模型 ε = 0.4，先验同上，长序列按每 10 次出现分块近似）。
- 打分函数与判定阈值（运行前写定）：
  - 指标：最佳解的逐位准确率；“错误解胜出”= 最佳解的（同一目标下的）得分高于真实明文的得分。
  - **支持 H004** 的条件：存在某个 λ，使得在 L = 50 与 L = 75 两个长度上，轮换感知求解器的平均准确率都比基线**高出至少 0.2**，且逐试验配对符号检验 p < 0.0033（0.01 按 3 个 λ 做 Bonferroni 校正）。
  - 另行报告与 Z32 直接相关的 L = 32：是否有某个 λ 使得 ≥ 50% 的试验准确率 ≥ 0.5。
- 零假设对照设计：同一密文上的基线求解器即为对照（配对比较）。
