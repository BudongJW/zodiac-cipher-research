# M5 综合报告：Z13 / Z32 能被破译吗？

> 日期：2026-09-25 · 汇总 M0–M4、方向 A（字形核对）与方向 E（地图几何）的全部结果。
> 分报告：[m0-report](m0-report.md) · [m2-report](m2-report.md) · [m3-report](m3-report.md) · [m4-report](m4-report.md) · [glyph-report](glyph-report.md) · 假设 [H001](../hypotheses/H001-z32-key-reuse.md) / [H002](../hypotheses/H002-z13-key-frame.md) / [H003](../hypotheses/H003-z32-map-lookelsewhere.md)

## 1. 一句话结论

**仅凭现有密文，Z13 与 Z32 都无法被可靠破译；历来的 30 条破译声明中没有一条具备证据价值。** 要取得突破，必须依靠密文以外的新信息。

## 2. 我们做了什么

| 阶段 | 内容 | 关键结果 |
|---|---|---|
| M0 / M1 | 自建工具链（`zkc`），复现已解的 Z408、Z340 | 两者逐字复现；盲解准确率 Z408 100%、Z340 95%（AZdecrypt 5-gram） |
| M2 | 短密文可解性基线、重复结构检验、Z13 姓名空间 | 长度 ≤ 150 时 100% 的试验中错误解得分高于真实明文；Z32 与 Z340 式体制一致，Z13 不一致；Z13 按原转录极难是普通人名 |

## 3. 主要发现

### 3.1 关于 Z32

1. **体制**：Z32 的符号重复程度（32 个符号中 29 个不同）正是 Zodiac 在 Z408 / Z340 中使用的同音替换（同音符号按顺序轮换）的典型结果（P ≈ 0.57）。简单替换几乎不可能产生这种结构。
2. **密钥**：Z32 **没有**沿用 Z340 或 Z408 的密钥，至少在 42 种简单换位内是如此（H001：p = 0.51 / 0.18，检验功效 92%）。最可能的情形是同类体制、新密钥。
3. **可解性**：在 Zodiac 式密钥下，32 字符的密文**总能**被“解”成比真实明文更通顺的错误读法（M2：24 次试验全部如此，得分中位数高出 70 分）。因此，任何只凭“读得通”来论证的 Z32 解都没有证据价值。
4. **现有声明**：Grinell、Cragle、Stampher 等“弧度 + 英寸”读法都符合重复模式，但：
   - 一个很小的文法就能生成 153 条同样符合的指令（65 种组合）；若第 26 位为独立符号，则为 702 条（220 种组合）；
   - 它们与已知密钥的一致只在偶然水平；
   - 它们的地理“命中”要么在自身规则下并不成立（Grinell 的读法距其目标 2.22 英里），要么在偶然概率之内（H003）。

### 3.2 关于 Z13

1. **体制**：Z13 的重复程度（13 个符号中 8 个不同）与 Zodiac 的同音密钥**不相符**（2 万次模拟中 0 次），更接近简单替换，或者部分符号根本不是字母。
2. **决定性约束**：第 5、7、9 位的三个“圈 8”。若它们代表同一字母：
   - 1990 年普查的 7,809 万个“名+姓”组合中只有 21 个符合；
   - 165 万个普通英文片段中 0 个符合；
   - 也就是说，Z13 几乎不可能是一个普通人名。

   若它们不代表同一字母，则有成千上万个普通人名符合，任何一个名字的符合都没有证据价值。字形核对没有发现三个圈 8 之间有实质差异。
3. **已知密钥**：Z340 密钥给出的框架 `DREA_A_O__EDO` 只有弱信号（p = 0.014，未达预注册阈值，且做了 6 次比较）；Garlick 的 “DR EAT A TOTPEDO” 在其 676 种补全中排第 58。
4. **现有声明**：Bauer、Kelleher、Stewart 与密文直接矛盾；Garlick 与 Oranchak 专门构造的反例（STEVE PETE WEST、LAURA CATAPULT）同级；其余不可证伪。

### 3.3 方法层面的收获

- **“读得通”不是证据**：短密文下，目标函数（语言模型得分）会稳定地偏好错误解。
- **必须显式计入自由度**：变位、多步变换、通配符、换位族、几何约定……每一项都会成倍增加“偶然符合”的机会。
- **预注册 + 零假设对照 + 功效检验**这套流程在本项目中可行、成本低，适合作为今后评估任何 Z13 / Z32 声明的标准。
- **作者本人的错误与异常必须建模**：Z340 的一处 “H 移位”就足以把正确换位的得分压到接近噪声。

## 4. 什么样的新证据能改变结论

| 新证据 | 可能的作用 |
|---|---|
| Z13 原件或高分辨率图像 | 确认三个圈 8 是否完全相同，第 10、11 位字形；这会直接改变“是否可能是人名”的判断 |
| Zodiac 其他（未公开或新发现）的密文 | 若使用与 Z32 相同的新密钥，合并后的长度可能越过可解阈值（M2：约 200–340 字符） |
| Z32 所用地图的更多细节（原件上的铅笔痕迹、刻度） | 为“弧度 + 英寸”的几何解读提供独立约束，缩小约定上的自由度 |
| 与明文相关的外部线索（信件、证词中的专有名词） | 作为独立的明文片段（crib），可大幅降低短密文的不确定性 |

## 5. 对今后声明的评估清单

任何新的 Z13 / Z32 “破译”至少应提供以下内容，并可用本仓库的工具复核：

1. 逐位对应的明文与完整密钥（同一符号 = 同一字母；例外须事先声明）；
2. 方法的全部自由度（换位、错误、空符、变位、几何约定……）；
3. 与零假设的比较：随机密钥 / 随机打乱 / 随机旋转下，达到同等“效果”的概率（`zkc` 与 `scripts/` 中已有现成实现）；
4. 事先写定的判定标准（参照 `hypotheses/` 的模板）；
5. 对 Z13：给出其读法在 [m2-report](m2-report.md) §4 姓名基线中的位置；对 Z32：给出其读法在 [m3-report](m3-report.md) §3 文法基线与 [H003](../hypotheses/H003-z32-map-lookelsewhere.md) 几何基线中的位置。
