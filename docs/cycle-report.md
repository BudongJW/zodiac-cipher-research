# 方向 F 报告：Zodiac 的同音符号轮换习惯——一条可以自行利用的新约束

> 日期：2026-09-27 · 探索性分析（非预注册；据此提出的可检验假设见 [H004](../hypotheses/H004-cycle-aware-solver.md)）
> 代码：`zkc/cycles.py`、`scripts/cycle_analysis.py`；结果：`results/cycle_analysis.json`。

## 1. 结论摘要

| 发现 | 数据 |
|---|---|
| Z408 中同音符号**按固定顺序轮换**使用 | 后继一致率 0.733，随机打乱 0.442 ± 0.015（z = 19.3） |
| Z340 中的轮换**出现在密文书写顺序（逐行）而非明文阅读顺序** | 书写顺序 0.566 对随机 0.471（z = 5.9）；阅读顺序 0.484（z = 0.8，无信号） |
| 由此得到的“同音分配 + 轮换”模型在 32 字符窗口上**确有区分力** | 真实 Z408 / Z340 窗口中，真实明文在“同样符合重复模式的英文片段”里的中位百分位为 1–9%，进入前 10% 的比例 57–89%（留一法先验） |
| 语言求解器在短密文上找到的“更像英文的错误解”大多**违反**轮换习惯 | 合成 32 字符密文：96% 的试验中真实明文的轮换似然更高（ε = 0.2）；50 字符以上 100% |
| 对 Z32 现有声明 | 无一在语言、轮换、几何三方面同时突出；DMW / Stampher 与 Reese 的读法轮换似然很低（约第 90 百分位） |

**意义**：这是一条**不依赖任何外部新材料**的新约束，来源是 Zodiac 自己在已解密文中留下的书写习惯。它本身不足以唯一确定 Z32 的明文，但它提供了此前所有分析（只看“重复模式是否符合”与“是否像英文”）都没有用到的信息。

## 2. 轮换的度量

**后继一致率**：对每个有多个同音符号的明文字母，统计“某符号之后，同一字母下一次出现时最常用的那个符号”所占比例。严格轮换时接近 1；随机选取同音符号时接近 1/k。以“在每个字母内部随机打乱符号顺序”作为零假设。

| 序列 | 后继一致率 | 随机打乱 | z | 同一符号连续重复率 |
|---|---|---|---|---|
| Z408（书写顺序 = 阅读顺序） | 0.733 | 0.442 ± 0.015 | **19.3** | 0.053 |
| Z340 明文阅读顺序 | 0.484 | 0.471 ± 0.016 | 0.8 | 0.202 |
| **Z340 密文书写顺序（逐行）** | 0.566 | 0.471 ± 0.016 | **5.9** | 0.085 |
| Z340 密文按列顺序 | 0.504 | 0.470 ± 0.017 | 2.0 | 0.194 |

**解读**：Z340 的作者很可能先按换位路径把明文字母排进 20×17 网格，再**逐行书写密文、边写边轮换**同音符号。这一顺序与已发表的 Z340 解相符，也意味着：**若 Z32 用同样的方式制作，轮换约束直接作用于 Z32 的书写顺序**，与是否存在换位无关。

## 3. 模型

每个明文字母有 k 个同音符号，排成一个循环，起点随机；每次出现时指针前进一步，以概率 1 − ε 使用指针所指的符号，以概率 ε 随机选一个。候选明文的**轮换对数似然**只取决于每个字母各次出现所用符号的“相等 / 不等”结构，k 对该字母在 Z408 / Z340 中的同音数上下各放宽 1 后取平均。

- 拟合的错误率：Z408 **ε = 0.20**，Z340（书写顺序）**ε = 0.40**；
- 这个模型同时编码了两种习惯：**同音分配**（常用字母分到更多符号，罕用字母只有 1–2 个）与**按序轮换**。

## 4. 区分力验证

| 检验 | 前 10% 比例 | 中位百分位 |
|---|---|---|
| 真实 Z408 窗口（45 个，先验只用 Z340 密钥） | **0.82–0.89** | 0.01 |
| 真实 Z340 书写顺序窗口（28 个，先验只用 Z408 密钥） | **0.57–0.61** | 0.06–0.09 |
| 消融：ε = 1（只保留同音分配，不轮换）——Z408 / Z340 | 0.67 / 0.50 | 0.04 / 0.11 |
| 合成检验（各字母同音数在先验范围内随机） | 0.76–0.77 | 0.01–0.03 |

- “前 10% 比例”：真实明文的轮换似然排在同样符合重复模式的英文片段前 10% 的窗口比例。
- 消融显示：**同音分配**本身已有区分力（50–67%），**轮换**在此基础上进一步提高（至 57–89%）。
- 大致相当于在“符合重复模式”的候选之外，再提供约 3–6 bits 的信息。

**与语言求解器的错误解比较**（复用 M2 / B1 的合成密文，其生成时为严格轮换）：

| 长度 | 真实明文轮换似然高于错误解的比例（ε = 0.2 / 0.4） | 似然差中位数 |
|---|---|---|
| 32 | 0.96 / 0.67 | +3.5 / +0.4 |
| 50 | 1.00 / 1.00 | +12.6 / +5.4 |
| 100 | 1.00 / 1.00 | +51.7 / +32.2 |

即：M2 中“总能找到更像英文的错误解”的那些错误解，大多**不符合** Zodiac 的轮换习惯。这提示一个可检验的假设——**把轮换似然加入求解器的目标函数，可能降低可解长度的门槛**（[H004](../hypotheses/H004-cycle-aware-solver.md)）。

## 5. 应用于 Z32

基准：普通英文中符合 Z32 重复模式的 584 个 32 字母片段。百分位越小越好。

| 读法 | 百分位（ε = 0.2，Z408 式） | 百分位（ε = 0.4，Z340 式） |
|---|---|---|
| Burke 2019：OKAY I SEVEN INS SOUTH OF DIABLO MT PEAK | **0.00** | **0.00** |
| Burke 2018：COUPLED WITH THE MAP IN WDVC INCHES TWO | 0.23 | 0.11 |
| Cragle：THREE RADIANS FROM MOUNT AREA TWO INCH | 0.41 | 0.13 |
| Grinell 2020：ESTIMATE FOUR RADIANS AND FIVE INCHES | 0.55 | 0.31 |
| DMW 2019 / Stampher：IN THREE AND THREE EIGHTHS RADIANS TEN | 0.86 | 0.90 |
| Reese（密文顺序） | 0.95 | 0.89 |

- **Burke 2019** 的读法轮换似然最高：字母 O 的四次出现依次用了 C、R、⊙、C（恰好是 k = 3 的完整循环），K 只在两端出现且同符号（符合 K 只有 1 个同音符号的习惯）。但这条读法语句生硬（“OKAY I SEVEN INS…”），语言得分也远低于无约束求解，**不应据此视为解**。
- **DMW / Stampher 与 Reese** 的读法轮换似然处于基准的第 86–95 百分位，即它们要求 Zodiac 采用与其已知习惯相当不符的同音用法。
- “弧度 + 英寸”文法的 153 条候选中，轮换似然进入基准前 10% 的只有 1–4 条（如 AT TWELVE INCH ALONG FOUR RADIANS WEST、AT EIGHTEEN INCH AT TWO RADIAN ALONG IT），都不是已有声明。

## 6. 局限

1. Z32 若采用了不同的制作流程（例如不轮换，或按列书写），模型的区分力会下降；Z340 本身的轮换已明显弱于 Z408。
2. 同音数先验取自 Z408 / Z340；Z32 用的是新密钥，其同音分配可能不同。
3. 合成检验中生成与打分使用同一模型，结果偏乐观；真实数据验证（第 4 节）更可信。
4. 这是探索性分析：第 5 节的排名只作描述，不作为任何读法成立与否的判定。
