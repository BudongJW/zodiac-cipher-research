# M4 报告：密钥复用假设检验（H001、H002）

> 日期：2026-09-25 · 对应路线图 [roadmap.md](roadmap.md) 方向 C。
> 假设在运行前已单独提交（预注册提交 `87f0ec7`）：[H001](../hypotheses/H001-z32-key-reuse.md)、[H002](../hypotheses/H002-z13-key-frame.md)。
> 脚本 `scripts/m4_key_reuse.py`；结果 `results/m4_key_reuse.json`。

## 1. 结论摘要

| 假设 | 内容 | 结果 | 结论 |
|---|---|---|---|
| **H001** | Z32 沿用 Z340 / Z408 密钥（27 / 25 个共有符号固定），并可能叠加 42 种简单换位之一 | Z340：p = 0.51；Z408：p = 0.18；**检验功效 92%** | **不支持**：直接沿用旧密钥基本可以排除 |
| **H002** | Z13 在 Z340 / Z408 密钥下的框架比随机框架更易补成英文 | 6 个变体中最小 p = 0.014（Z340 / 原顺序），未达预注册阈值 0.01 | **不支持**；存在弱信号，Garlick 读法仅排第 58 / 676 |

## 2. H001：Z32 × 已知密钥 × 简单换位

- 候选读取顺序 42 种：原顺序、逐行倒读、蛇形、按列读，以及 2×17 网格上全部 16 种 (1, dc) 抽取，并各含逆序（去重后）。
- Z340 密钥下只有 `[`、`?` 两个自由符号，穷举；Z408 密钥下有 4 个，用坐标上升。
- 所有读取顺序中的最高分与“密钥字母随机打乱”的零假设无差别；最佳读法都是乱码（如 `NPYAFTWBITDRIOTEROADPSAGEONERINY`）。
- **功效检验**：把真实 Zodiac 明文用 Z340 密钥加密并随机换位后重做检验，92% 的情形能被识别。因此阴性结果有实际意义。

**与 M2 的合并解读**：M2 显示 Z32 的重复结构正是 Zodiac 式同音替换（轮换）的典型结果；H001 显示它没有沿用 Z340 / Z408 的密钥。最一致的图景是：**Z32 使用同一类体制，但换了一张新密钥**。而 M2 / B1 已经表明，这类体制下 32 字符**无法**靠语言统计识别真实明文。

## 3. H002：Z13 × 已知密钥框架

- Z340 密钥给出框架 `DREA_A_O__EDO`（Garlick 读法的基础）。在 676 种补全中，语言模型最偏好 `DREATATOTHEDO`（“DR EAT A TOT HE DO”），Garlick 的 `DREATATOTPEDO` 排第 58。
- 该框架的最佳补全得分高于 98.6% 的随机框架（p = 0.014），但：
  - 未达预注册阈值 0.01；
  - 共检验 6 个变体，Bonferroni 校正后阈值为 0.0017；
  - 最佳补全本身并不成句。
- 其余 5 个变体（逆序、删去圈 8、Z408 密钥）均无信号。

**结论**：没有统计证据表明 Z13 沿用了已知密钥。Z340 框架的弱信号只能作为今后**另行预注册**检验的线索，不能在同一数据上继续调整参数去追逐它。

## 4. 截至 M4 的总体图景

| 问题 | 证据 | 当前判断 |
|---|---|---|
| Z32 用的是什么体制？ | M2 / B1b：重复结构与 Z340 式同音替换（轮换）一致（P ≈ 0.57） | 很可能与 Z408 / Z340 同类 |
| Z32 沿用了旧密钥吗？ | H001：p = 0.51 / 0.18，功效 92% | 基本排除（至少在 42 种简单换位内） |
| 仅凭 Z32 密文能解吗？ | M2 / B1：L = 32 时 100% 的试验中错误解得分高于真实明文 | **不能**：必须有密文以外的独立约束 |
| 已有 Z32 声明可信吗？ | M3：均为 B / D 级；与已知密钥的一致在偶然水平；小文法内即有 153 条指令同样符合 | 均无证据价值 |
| Z13 用的是什么体制？ | M2 / B1b：重复过多，不符合 Z408 / Z340 式密钥（0 / 20,000） | 更接近简单替换，或部分符号不是字母 |
| Z13 是一个普通人名吗？ | M2 / B2：原转录下 7,809 万个“名+姓”中仅 21 个符合，英文片段 0 个 | 若圈 8 为同一字母则几乎不可能；否则候选成千上万 |
| Z13 沿用了旧密钥吗？ | H002：最小 p = 0.014（未达阈值） | 无证据；存在待独立检验的弱信号 |

## 5. 后续方向（按优先级）

以下方向都需要**密文以外的新信息**。M2 / M4 已经表明，仅靠密文的统计方法在 Z13 / Z32 上已接近极限。

> 更新（同日）：第 1 项已完成，见 [glyph-report.md](glyph-report.md)；第 2 项以预注册检验 [H003](../hypotheses/H003-z32-map-lookelsewhere.md) 完成了可用数据范围内的部分；总结见 [m5-report.md](m5-report.md)。

1. **字形核对（方向 A，需要高清扫描件）**：Z13 第 10、11 位与 Z32 的 6 个争议字形会直接改变重复模式。例如 M2 显示，若 Z13 第 11 位是反写 N，符合的名字会从 21 个增至 509 个。需要取得原件或高清扫描，并逐一记录备选读法。
2. **地图几何（方向 E，需要地图扫描与地名数据）**：Z32 唯一的强外部约束。需要：同版 Phillips 66 地图的高清扫描与地理配准；1970 年前后湾区地点的核实坐标（案发地、警局、学校等）；预注册的解析规则与“随机点命中”零假设。M3 的文法已经给出 65 种“弧度 + 英寸”组合，可直接作为输入。（本轮曾尝试从维基百科获取案发地坐标，但页面未提供，而凭记忆的坐标误差可达数公里，不足以做 2 公里级的命中检验，故推迟。）
3. **Z13 的 Z340 框架弱信号（H002 的后续）**：预注册一个独立检验，例如只用 Zodiac 其他信件的用语构建语言模型，检验 `DREA_A_O__EDO` 框架的补全是否仍显著。
4. **Z13 与 Z32 的联合模型**：两者共享 5 个符号（A、E、M、`[`、⊕）。但合并后也只有 45 个字符，M2 / B1 显示 L = 50 时仍然 100% 不可识别，因此单独进行的价值很低，只适合在方向 1、2 提供新约束后再考虑。

方向 1、2 都需要下载外部资料（扫描件、地图、地名数据），开始前会先说明来源与许可并取得同意。
